# PolyMarket_UPorDOWN_Bot


## 1. 参数详解<br>
### 1.1 入场时间窗口<br>
```
参数	                  当前值	    含义	                    为什么这样设
ENTRY_SECONDS_MAX	    40 秒	    最早在收盘前 40 秒入场	    太早价格还可能反转
ENTRY_SECONDS_MIN	    15 秒	    最晚在收盘前 15 秒入场	    太晚订单可能来不及成交
WAKE_BEFORE	          55 秒	    收盘前 55 秒开始监控	      留出数据拉取和计算时间
```

时间线示意<br>
  T-55s  →  机器人唤醒，开始拉数据<br>
  T-40s  →  进入入场窗口（开始评估是否下注）<br>
  T-15s  →  入场窗口关闭（最后机会）<br>
  T-0s   →  周期结束，市场结算"<br>


### 1.2 Polymarket 价格过滤<br>
Polymarket 上的价格 = 市场认为该方向获胜的概率。买入 $0.94 意味着花 94 分赌赢了拿 $1，净收益约 6.4%。

```
参数	          BTC	    ETH	    说明
PRICE_MIN	    0.95	  0.93	  低于此价格不入场（不够确定）
PRICE_MAX	    0.97	  0.97	  高于此价格不入场（利润太薄）
```

BTC 要求更高是因为 BTC 波动性更大，同样的 delta 下反转风险更高。
```
买入价格	若胜利净收益率	手续费（$10下注）	综合评价
0.92	~8.7%	~$0.013	利润好，但需更强信号
0.94	~6.4%	~$0.008	推荐区间
0.96	~4.2%	~$0.004	推荐区间
0.97	~3.1%	~$0.002	利润偏薄，谨慎
0.99	~1.0%	~$0.000	不入场（PRICE_MAX限制）
```

### 1.3 Binance 技术分析参数<br>
Window Delta（窗口偏差）<br>
当前价格 vs 本周期开盘价的偏差百分比。偏差越大，说明方向越明确。
```
参数	              值	                含义
DELTA_SKIP	      0.001 (0.1%)	      偏差低于此值：价格还在开盘附近，方向不明，直接跳过
DELTA_WEAK	      0.0015 (0.15%)	    偏差在 0.1%–0.15%：弱信号，delta_weight = 1
DELTA_STRONG	    0.003 (0.3%)	      偏差超过 0.3%：强信号，delta_weight = 5 或 7
```

信心评分（Confidence Score）<br>
综合 Window Delta 权重 + 微动量方向，归一化到 0–1 之间。
```
参数	值	含义
MIN_CONFIDENCE	0.45	至少需要 4.05/9 分才入场，过滤弱信号
```

```
"评分构成（满分 9 分）
Delta 权重（最高 7 分）：偏差越大，权重越高
  偏差 > 1.0%  →  7 分
  偏差 > 0.3%  →  5 分
  偏差 > 0.15% →  3 分
  偏差 > 0.1%  →  1 分

微动量（最高 2 分）：最近 2 根 1 分钟 K 线方向与 Delta 一致时 +2 分

Confidence = 总分 / 9"

```



ATR 波动率过滤<br>
ATR（平均真实波幅）衡量历史平均波动范围。如果当前周期的振幅超过历史均值的 1.2 倍，说明行情异常，跳过本次入场。
```
参数	                值	          含义
ATR_PERIODS	        5	            计算过去 5 个 5 分钟周期的平均振幅
ATR_MULTIPLIER	    1.2	          当前振幅 > 历史均值 × 1.2 时跳过（避免剧烈波动时入场）
```


### 1.4 手续费计算
Polymarket 5 分钟加密市场采用动态手续费，官方公式为：

_fee = (amount / price) × 0.25 × (price × (1 - price))²_

手续费在价格 0.50 时最高（1.56%），越接近 0 或 1 越低，在本机器人的入场区间（0.92–0.97）极低：

```
入场价格	       手续费率	        $10 下注的手续费	    说明
0.50	         1.56%	        $0.156	          理论峰值（不会入场）
0.92	         0.13%	        $0.013	          ETH 最低入场线附近
0.94	         0.08%	        $0.008	          BTC 最低入场线附近
0.96	         0.04%	        $0.004	          接近最大入场价
0.97	         0.02%	        $0.002	          最大入场价
```


入场前会自动计算扣费后净利润，若净利润 ≤ 0 则跳过。

### 1.5 复利投入
机器人不固定下注金额，而是用当前本金（bankroll）作为每次下注金额：

```
情况	        本金变化
胜利	        bankroll += 净利润（毛收益 - 本金 - 手续费）
失败	        bankroll -= 本金 + 手续费
保底	        bankroll 最低为 $1，不会归零
```

```
"复利示例（初始 $10，入场价 0.95）
第1次胜：$10 → 净利润 $0.52 → bankroll = $10.52
第2次胜：$10.52 → 净利润 $0.55 → bankroll = $11.07
第3次败：$11.07 → 亏损 $11.07 → bankroll = $1.00（保底）"
```


## 2. 入场过滤条件（全部通过才下注）

```
#	      过滤条件	                                              不通过时
1	      Polymarket 价格 ≥ PRICE_MIN（BTC:0.95 / ETH:0.93）	    SKIP
2	      Polymarket 价格 ≤ PRICE_MAX（0.97）	                    SKIP
3	      ATR 过滤：当前振幅 ≤ 历史均值 × 1.2	                      SKIP
4	      Delta ≥ DELTA_SKIP（0.1%），不能太靠近分界线	              SKIP
5	      Confidence ≥ MIN_CONFIDENCE（0.45）	                  SKIP
6	      Binance 方向 与 Polymarket 方向一致	                    SKIP
7	      扣除手续费后净利润 > 0	                                  SKIP
8	      钱包余额 ≥ 当前下注金额（Live 模式）	                      SKIP
```


## 3. 运行模式
```
模式	              命令	                                          说明
Paper（默认）	      python crypto_bot.py --paper	                模拟下注，不上链，用于测试策略
Dry Run	          python crypto_bot.py --dry-run	              拉取真实数据，只打印分析，不执行
Live	            python crypto_bot.py --live	                  真实资金，需要 .env 配置私钥
自定义金额	        python crypto_bot.py --paper --amount 50	    设置初始本金为 $50
```

### Live 模式需要在 .env 文件中配置
```
POLY_PRIVATE_KEY=你的以太坊私钥
POLY_PROXY_WALLET=你的 Polymarket Proxy 钱包地址"
```

```

```
